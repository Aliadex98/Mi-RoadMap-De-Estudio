FASE 1.3 — PROYECTO INTEGRADOR DE FASE 1
🎯 PROYECTO FINAL FASE 1 — "El Juego del Destino"

Un juego de consola que combine TODO lo aprendido:

Requisitos mínimos:

    Menú principal con opciones (jugar, ver historial, salir)

    Al menos 3 mini-juegos dentro:

        Adivinanza de número (con intentos limitados)

        Piedra, papel o tijera (vs "máquina")

        Trivia de preguntas (con puntaje)

    Sistema de puntaje acumulado

    Historial de partidas jugadas

    Validación de entradas del usuario

    Uso de funciones, condicionales, bucles, arrays y objetos básicos

Requisitos técnicos:

    Código dividido en funciones claras

    Sin código duplicado

    Comentado donde sea necesario

    README explicando cómo jugar

Criterio de "terminado":

    Se puede jugar de principio a fin sin errores

    El usuario no puede romperlo con entradas raras

    Tú puedes explicar cada función sin mirar el código
